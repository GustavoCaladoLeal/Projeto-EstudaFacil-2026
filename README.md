Estudantes costumam ter tarefas, trabalhos e prazos espalhados em diferentes lugares, como cadernos, 
mensagens e plataformas da instituição. Isso dificulta saber quais atividades devem ser realizadas primeiro
e aumenta o risco de perder prazos. O EstudaFácil será uma aplicação web para organizar tarefas acadêmicas 
em um único lugar

O meu objetivo e criar uma aplicação para cadastrar, organizar, filtrar e acompanhar tarefas acadêmicas, e
assim atendendo os estudantes que precisam controlar trabalhos, provas, atividades e respectivos prazos.
 
A aplicação permitirá:

- Cadastrar tarefas;
- Listar tarefas;
- Editar tarefas;
- Excluir tarefas;
- Filtrar tarefas;
- Marcar tarefas como concluídas

Login, notificações, aplicativo mobile e integração com calendários ficarão para versões futuras.

Utilizando as seguintes tecnologias:

- Java;
- Spring Boot;
- JavaScript;
- HTML e CSS;
- Banco de dados;
- API REST;
- Git e GitHub
